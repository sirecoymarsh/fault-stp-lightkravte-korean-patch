# LIGHTKRAVTE 한국어 번역 문체 가이드

## 1. 번역 원칙

- **의미 원본은 일본어(`ja`)**다. 영어와 중국어는 고유명 표기·생략된 주어·기술 개념을 확인하는 참고 자료일 뿐, 일본어와 충돌하면 일본어를 따른다.
- 직역투보다 장면에서 실제로 발화 가능한 자연스러운 한국어를 우선한다. 다만 의미, 인과, 수치, 강도, 화자의 태도는 바꾸지 않는다.
- 같은 일본어 문장이라도 화자·상황·앞뒤 문맥이 다르면 별도로 번역한다.
- 영어판이 덧붙인 농담, 설명, 욕설, 심리 묘사는 일본어에 근거가 없으면 가져오지 않는다.
- 한국어 문장부호는 `……`, `――`의 정서와 길이를 가능한 한 살리되, 읽기 어렵다면 자연스러운 `…`, `—`로 정돈할 수 있다. **런타임 토큰은 절대 손대지 않는다.**

## 2. 런타임 토큰과 줄바꿈

- `<br>`, `<tip="...">`, `</tip>`, `<ruby="...">`, `</ruby>`, `<i>`, `<b>`, `<mspace=...>` 등 태그의 **종류·개수·속성값을 정확히 보존**한다.
- `<br>` 위치는 원문과 같은 의미 단위에 두는 것을 기본으로 한다. 한국어 어순 때문에 옮길 필요가 있으면 태그 개수는 그대로 유지한다.
- `tip`의 키, `ruby`의 속성값, 내부 ID는 번역하지 않는다. 표시 본문만 한국어로 옮긴다.
- 숫자, 퍼센트, CLASSIFIED, MADEC 단계명, 영문 약어는 의미를 바꾸지 않는다.
- 원문이 말줄임표뿐인 행은 임의의 대사를 만들지 않는다.

## 3. 한국어 서술과 대사

- 장면 서술은 기본적으로 `-했다/-였다` 문어체. 카지의 즉각적인 속마음은 자연스러운 구어형 의문·감탄을 허용한다.
- 일본어의 생략된 주어를 매 문장 복원하지 않는다. 한국어에서도 명확하면 생략한다.
- 일본어식 중복 호칭과 대명사는 자연스럽게 줄이되, 권력 관계를 드러내는 호칭은 보존한다.
- 말더듬은 글자를 기계적으로 반복하지 말고 한국어 호흡으로 옮긴다.
  - `あ あの…` → `저, 저기…`
  - `そ そんな…` → `그, 그럴 수가…`
  - 심한 공황에서는 음절 반복을 더 많이 남길 수 있다.
- `様`는 무조건 `님`으로 치환하지 않는다.
  - 왕족: `공주님`, `전하`, 장면에 따라 `셀피네 님`
  - 직업·연장자: `-님`, `-씨`, 직함
  - 친밀한 관계의 `ちゃん/君`: 이름, `-야`, `-군` 중 관계에 맞게 선택
- 전각 등호(`＝`)로 이어진 인명은 한국어에서는 공백으로 쓴다: `カージ＝オバーグ` → `카지 오버그`.

## 4. 세계관 용어

- `クラフト` 계열은 **크래프트**로 통일한다. 일반 명사 craft(공예)와 혼동되는 문장에서는 문맥으로 구분한다.
- `ライトクラフト`는 작품의 write/light 중의성을 보존하기 위해 **라이트크래프트**로 고정한다. ‘쓰기 크래프트’, ‘빛 크래프트’로 풀어 바꾸지 않는다.
- `ピュリファイドマナ`는 **정제 마나**, `ヴィビリア`는 **비빌리아**. 같은 실체를 가리키더라도 원문이 선택한 명칭을 유지한다.
- `ファリナー`는 사람/직업이면 **파리너**, 운항편·탈것을 잡거나 타는 문맥이면 **파린**으로 구분한다.
- `ウォール街`는 현실의 월가가 아니라 **성벽 지구**다.
- `止り木`는 모임 장소 고유명 **횃대**로 쓴다.
- 상세 표기는 `terminology.json`과 `glossary.md`를 기준으로 한다.

## 5. 호칭과 관계 핵심

- 카지 → 플로라: 기본 존댓말, `플로라 님`.
- 카지 → 셀피네: `셀피네 공주님` 또는 문맥상 `전하`.
- 카지 → 켄드리드·장인·리그스·미샤: 기본 존댓말. 급박하거나 친밀한 순간에도 관계가 갑자기 반말로 뒤집히지 않게 한다.
- 소네타 → 카지: `카지 씨`; 자기 자신은 장난스럽게 `미치`.
- 쿠알라 → 카지: `카지 오빠`.
- 메를리사 → 카지: `카지야`.
- 소네타 → 리토나: 장난스럽게 `리토나 선배`; 리토나는 같은 나이라며 이를 싫어한다.
- 셀피네의 평상시 말투와 군주 모드는 반드시 구분한다.

## 6. 장면별 유의점

- 기술 설명은 자연스러움보다 **작동 원리와 인과 정확성**을 우선한다. `해상력`, `이미지 서클`, `헬리코이드`, 마나의 저장·공명·인쇄 과정을 임의로 단순화하지 않는다.
- 음식 장면은 향·재료·조리 순서의 감각을 살리되, 원문에 없는 맛 평가를 추가하지 않는다.
- 폭주·전투 장면의 비명은 가독성보다 연출을 우선한다. 대문자·굵게·자간 태그를 보존하고, 판독되는 명령만 번역한다.
- 코미디 장면은 템포를 살리되 영어판의 추가 농담에 의존하지 않는다.
- `CLASSIFIED`, 검은 네모, 세계번호처럼 의도적으로 난독화된 정보는 해독하거나 보충하지 않는다.

## 7. 품질 검수 체크

1. UID별 누락·중복이 없는가.
2. 모든 `required_tokens`의 종류와 개수가 동일한가.
3. 고유명·크래프트·지명 표기가 용어집과 일치하는가.
4. 화자의 존대 관계와 말투가 앞뒤 행에서 이어지는가.
5. 일본어 한자·가나가 의도 없이 남지 않았는가.
6. 영어판만의 추가 의미가 섞이지 않았는가.
7. 수치, 부정, 조건, 비교 범위가 바뀌지 않았는가.
8. 한국어로 소리 내어 읽었을 때 실제 대사처럼 자연스러운가.
